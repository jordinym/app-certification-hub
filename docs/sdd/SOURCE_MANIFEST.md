# Baseline obligatorio para consolidación

El instalador **importa estos archivos exactos desde el checkout actual del usuario**. No inventa ni sintetiza su contenido. El ZIP no contiene copias potencialmente desactualizadas del código ni de estos archivos originales.

| Archivo | Razón |
|---|---|
| `docs/PRODUCT_SPEC.md` | Objetivo/producto |
| `docs/BACKLOG.md` | Alcance S0–S4 |
| `docs/IMPLEMENTATION_PLAN.md` | 37 tareas y AC originales |
| `docs/UI_SPEC.md` | Rutas/estados/UI |
| `docs/ui-reference.png` | Referencia visual original |
| `docs/ARCHITECTURE.md` | Arquitectura |
| `docs/DECISIONS.md` | ADR/decisiones |
| `docs/COMPATIBILITY.md` | Restricciones versionado |
| `docs/DEPLOYMENT.md` | Runbook remoto |
| `docs/DOCKER_DEV.md` | Runbook local |
| `docs/S0_REPORT.md` | Evidencia histórica S0 |

Otros documentos del antiguo `docs/` se conservan **en el respaldo fuera del repositorio activo** para comparación, pero no como segunda fuente de verdad. `docs/agents/ROLES.md` antiguo se reemplaza por `.agents/roles/`.
